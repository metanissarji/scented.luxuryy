# Scented Luxury — by Mustafa

Prototype website for [@scented.luxuryy](https://www.instagram.com/scented.luxuryy/) — luxury & niche perfumes, delivery across the country.

Static site: a single `index.html` (Arabic, RTL). No build step.

## Run locally
Open `index.html` in a browser, or serve the folder with any static server.

## Deploy
Vercel → import this repo → Framework preset: **Other**, no build command, output directory: `./`.

## Editing
- WhatsApp number: `WA_NUMBER` at the top of the `<script>` in `index.html` (format `9725XXXXXXXX`).
- Products, prices and notes: the `PRODUCTS` array in the same script.
- Brand colors: CSS variables in `:root`.
